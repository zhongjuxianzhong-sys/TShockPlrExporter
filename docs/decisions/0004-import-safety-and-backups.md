# 0004 导入前强制路径、离线和备份保护

- 状态：已接受
- 日期：2026-09-11
- 取代：无

## 背景

导入会覆盖服务器端角色。任意路径、在线旧会话或备份失败都可能造成越权读写、数据回滚或不可恢复覆盖。

## 决策

- 导入参数只能是 `PlayerImports` 目录下的普通 `.plr` 文件名。
- 读取并规范化 `.plr` 后，先踢出目标账号并确认离线。
- 目标已有 SSC 时，必须先成功生成导入前备份。
- SSC 写入使用事务；备份失败、离线超时或玩家重新上线时中止导入。
- 源导入文件成功后不自动删除。

## 后果

- 导入操作更慢，但失败边界更清晰。
- 管理员需要保留并归档 `PlayerSscBackups`。
- 恢复流程可以基于备份 `.plr` 重新执行导入，而不是手工改数据库。

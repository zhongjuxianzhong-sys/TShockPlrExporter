# 0002 数据库访问使用独立连接

- 状态：已接受
- 日期：2026-09-11
- 取代：无

## 背景

导出运行在后台线程，ADO.NET 连接不是线程安全的。复用 `TShock.DB` 的共享连接会与服务器自身查询相互干扰；SQLite 还存在锁和读写模式差异。

## 决策

- 插件按 TShock 配置创建自己的数据库连接。
- 读取路径只执行 `SELECT`，SQLite 读取连接使用只读模式。
- 导入写回使用独立读写连接和事务。
- 数据库列按名称读取，以兼容 TShock 版本之间的字段增减。

## 后果

- 后台任务不会争用 TShock 的共享连接。
- 配置解析、SQLite/MySQL 差异和连接生命周期由插件自行维护。
- 数据库配置变化时必须更新后端 runbook 和测试。

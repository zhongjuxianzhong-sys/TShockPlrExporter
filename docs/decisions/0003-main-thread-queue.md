# 0003 使用主线程队列访问游戏状态

- 状态：已接受
- 日期：2026-09-11
- 取代：无

## 背景

批量导入导出不能阻塞 TShock 主循环，但发送网络消息、同步在线玩家 SSC、踢出玩家和回退保存都必须访问 Terraria/TShock 的主线程状态。

## 决策

- 导入导出主体在后台线程执行。
- 必须访问主线程的动作通过 `MainThreadQueue` 排队。
- `Invoke` 阻塞等待并设置 15 秒超时，`Enqueue` 用于不等待的消息投递。
- 控制台结果直接写日志，避免结果投递依赖 `GameUpdate` 钩子。

## 后果

- 主循环不会被长任务阻塞。
- 队列停摆、主线程卡顿和卸载竞态需要专门诊断。
- 从主线程调用 `Invoke` 会导致死锁，必须保持调用方分离。

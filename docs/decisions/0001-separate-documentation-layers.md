# 0001 独立维护文档层

- 状态：已接受
- 日期：2026-09-11
- 取代：无

## 背景

根 README 同时承担用户安装说明、命令参考、内部实现和排障手册。随着 SSC、在线玩家、数据库后端、备份和主线程调度等风险场景增加，单一文档会持续膨胀，读者也难以判断应先看哪一部分。

## 决策

- 根 `README.md` 保留用户安装、命令、权限、目录、限制和 FAQ。
- `docs/architecture.md` 维护组件边界、数据流、并发模型和安全不变量。
- `docs/runbooks/` 按风险场景维护可执行的诊断、恢复和验证流程。
- `docs/decisions/` 记录关键架构取舍。
- `AGENTS.md` 明确各类代码变更需要同步更新的文档层。

## 后果

- 用户文档与工程维护文档可以独立演进。
- 排障流程可以按场景路由，而不是继续堆进 README。
- 修改行为时需要同时承担文档更新成本。
